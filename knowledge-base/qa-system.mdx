# Q&A Learning System

One of BestChatBot's most powerful features is its ability to **learn from real conversations** happening in your Discord server. When moderators answer questions, the bot remembers those answers for the future.

## How It Works

<Steps>
  <Step title="A User Asks a Question">
    Someone in your community asks a question in a channel where the bot is active.
  </Step>

  <Step title="A Moderator Answers">
    A server moderator or admin provides a helpful answer to the question.
  </Step>

  <Step title="BestChatBot Evaluates the Exchange">
    The bot applies intelligent filtering to determine if the moderator's answer adds valuable, knowledge-base-related information. Only responses that contribute new, factual knowledge are captured as **Q&A entries**. Casual replies, off-topic messages, and redundant information are automatically filtered out.
  </Step>

  <Step title="Future Questions Get Better Answers">
    When similar questions come up in the future, the bot can draw from these real moderator answers to provide more accurate, community-specific responses.
  </Step>
</Steps>

## Viewing Q&A Entries

You can view all captured Q&A pairs in the **Document Manager**:

1. Open the **Document Manager** from the sidebar
2. Look for entries marked as **Q&A** sources
3. Each entry shows the original question and the moderator's answer

<Frame>
  <img src="/images/qa-screen-front-end.png" alt="Auto Learning tab showing captured Q&A entries" />
</Frame>

Click on any Q&A entry to see the full question and the moderator's answer:

<Frame>
  <img src="/images/qa-screen-detailed-front-end.png" alt="Q&A Content modal showing the question and moderator answer" />
</Frame>

<Note>Q&A entries are included in the knowledge base just like uploaded documents and scraped pages. After a [rebuild](/knowledge-base/rebuild), the bot can use them to answer future questions.</Note>

<Warning>The Q&A Learning System is a **Discord-only** feature. It is not available for web widget workspaces.</Warning>

## Tips for Better Q&A Learning

- **Encourage detailed moderator answers**:The more complete the answer, the better the bot learns
- **Keep answers on-topic**:Off-topic responses may confuse the bot
- **Rebuild periodically**:Rebuild the knowledge base to incorporate recent Q&A entries
