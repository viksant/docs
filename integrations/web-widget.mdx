# Web Widget

<Note>The web widget is **coming soon**. This page will be updated when it launches.</Note>

We're building a chat widget you can embed directly on your website. Same AI, same knowledge base, new surface.

## What to Expect

The web widget will let your website visitors ask questions and get instant answers from the same knowledge base your Discord bot uses. One knowledge base, multiple channels.

## Planned Features

- **Drop-in script tag** for any website
- **Same knowledge base** as your Discord bot
- **Customizable appearance** to match your brand
- **No extra setup** if you already have a knowledge base

## Stay Updated

We'll announce the web widget launch through our Discord community and email updates. If you're on a paid plan, you'll get early access.
