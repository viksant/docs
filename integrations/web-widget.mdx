# Web Widget

Add a chat widget to your website so visitors can ask questions and get instant answers from your knowledge base. Same AI that powers your Discord bot, now on your website.

<Frame>
  <img src="/images/widget-on-website.png" alt="BestChatBot chat widget floating on a website" />
</Frame>

## What You Get

- **One line of code** — paste a script tag and you're done
- **Same knowledge base** as your Discord bot
- **Real-time streaming** — answers appear word by word
- **Customizable colors** to match your brand
- **Mobile friendly** — full-screen on small devices
- **No impact on your site** — runs in an isolated Shadow DOM

---

Before adding the widget to your website, make sure you have:

<Tip>If you already have a Discord bot running with a knowledge base, you can reuse the same workspace for the widget. One knowledge base, multiple channels.</Tip>

<Steps>
  <Step title="Open the Widget Manager" icon="grid-2">

    ```html
      data-api-key="rk_live_xxxxxxxxxxxxxxxxxxxx"
      defer>

    ```
  </Step>
</Steps>

## Install on Your Website

Paste the snippet into your website's HTML, just before the closing `</body>` tag:

```html
<!DOCTYPE html>
<html>
  <head>
    <title>My Website</title>
  </head>
  <body>
    <!-- Your website content -->

    <!-- BestChatBot Widget -->
    <script
      src="https://bestchatbot.io/widget/v1/chat.js"
      data-api-key="rk_live_xxxxxxxxxxxxxxxxxxxx"
      defer>
    </script>
  </body>
</html>
```

That's it. The widget will appear as a floating chat bubble in the bottom-right corner of your site.

<Warning>Never modify the `data-api-key` value. It's your widget's unique identifier.</Warning>

## How It Works

Once installed, the widget works like this:

1. **Page loads** → the script loads from BestChatBot's servers
2. **Widget appears** → a chat bubble shows in the bottom-right corner
3. **Visitor clicks** → the chat window opens
4. **Visitor asks a question** → the widget sends it to your knowledge base
5. **Answer streams in** → the response appears word by word in real time
6. **Sources shown** → relevant sources from your knowledge base are listed (expandable)

<Frame>
  <img src="/images/widget-chat-open.png" alt="Chat window open with a conversation showing streaming response" />
</Frame>

### Conversation Memory

The widget remembers the conversation within the same browser session. If a visitor navigates to another page, their chat history is preserved. Clicking the **+** button starts a fresh conversation.

<Tip>Conversation history is stored in the visitor's browser (localStorage). It's never shared between visitors or sent to third parties.</Tip>

## Security & Allowed Domains

The widget only works on domains you've approved. This prevents someone from copying your embed code and using it on their own site.

### Managing Allowed Domains

Go to **Widget Settings → Security** to manage your allowed domains.

<Frame>
  <img src="/images/widget-settings-security.png" alt="Widget security settings showing allowed origins and rate limit" />
</Frame>

**Supported formats:**

| Format | Example | What It Matches |
|--------|---------|-----------------|
| Exact URL | `https://example.com` | Only that exact domain |
| Wildcard | `*.example.com` | Any subdomain: `shop.example.com`, `blog.example.com` |

<Warning>You cannot use `*` alone as a domain. Wildcards must include at least a second-level domain (e.g., `*.example.com`).</Warning>

### Rate Limiting

Each widget has a built-in rate limit to prevent abuse. The default is **30 requests per minute** per widget, with an automatic per-visitor limit of 10 requests per minute.

You can adjust the rate limit in Widget Settings.

### Regenerating Your API Key

If you suspect your API key has been compromised, you can regenerate it:

1. Go to **Widget Settings → Security**
2. Click **Regenerate API Key**
3. Copy the new embed snippet
4. Update the snippet on your website

<Warning>Regenerating the API key immediately invalidates the old one. Update your website right away to avoid downtime.</Warning>

## Advanced: Programmatic API

For developers who want more control, the widget exposes a JavaScript API on `window.BestChatBot` after it loads.

### Available Methods

| Method | Description |
|--------|-------------|
| `BestChatBot.open()` | Open the chat window |
| `BestChatBot.close()` | Close the chat window |
| `BestChatBot.toggle()` | Toggle open/close |
| `BestChatBot.destroy()` | Remove the widget from the page entirely |
| `BestChatBot.sendMessage(text)` | Send a message programmatically |
| `BestChatBot.onReady(callback)` | Run a function when the widget is ready |
| `BestChatBot.onMessage(callback)` | Run a function when a new message arrives |

### Examples

**Open the widget when a button is clicked:**

```html
<button onclick="BestChatBot.open()">
  Chat with us
</button>
```

**Send a pre-filled question:**

```html
<button onclick="BestChatBot.sendMessage('How do I reset my password?')">
  Help with password
</button>
```

**Wait for the widget to be ready:**

```javascript
BestChatBot.onReady(() => {
  console.log('Widget is ready!')
})
```

<Note>The API is only available after the widget script has loaded. If you need to call it immediately, use `onReady()` to wait for initialization.</Note>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Widget doesn't appear">
    - Check that the `data-api-key` is correct
    - Verify your domain is in the allowed origins list
    - Open browser DevTools (Console tab) and look for `[BestChatBot]` warnings
    - Make sure the script tag has the `defer` attribute
  </Accordion>

  <Accordion title="Widget shows but doesn't respond">
    - Check that your knowledge base has content and has been rebuilt
    - Look for errors in the browser Console
    - Verify your subscription is active
  </Accordion>

  <Accordion title="Styling conflicts">
    The widget runs inside a closed Shadow DOM, so conflicts are extremely rare. If you see issues:
    - Check that you don't have a global `* { all: unset }` rule
    - Make sure no script is removing the `#bestchatbot-widget-host` element
  </Accordion>

  <Accordion title="Widget appears on wrong pages">
    The script tag loads on every page where it's included. To limit it:
    - Add the snippet only to specific page templates
    - Or use conditional loading with JavaScript:

    ```javascript
    if (window.location.pathname === '/support') {
      const script = document.createElement('script')
      script.src = 'https://bestchatbot.io/widget/v1/chat.js'
      script.setAttribute('data-api-key', 'rk_live_xxxx')
      script.defer = true
      document.body.appendChild(script)
    }
    ```
  </Accordion>
</AccordionGroup>
