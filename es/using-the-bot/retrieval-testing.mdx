# Pruebas de Recuperacion

La pagina de **Pruebas de Recuperacion** te permite chatear con tu bot directamente desde el dashboard. Usala para verificar las respuestas del bot, probar casos limite y asegurarte de que todo funcione antes de que tu comunidad lo vea.

## Como Usar las Pruebas de Recuperacion

<Steps>
  <Step title="Abrir Pruebas de Recuperacion">
    Navega a **Pruebas de Recuperacion** desde la barra lateral del dashboard.
  </Step>

  <Step title="Escribe una Pregunta">
    Usa el campo de chat en la parte inferior para escribir una pregunta, tal como lo haria un usuario en Discord.
  </Step>

  <Step title="Revisa la Respuesta">
    El bot responde en tiempo real con una respuesta en streaming. Veras la respuesta aparecer palabra por palabra, junto con las fuentes que uso.
  </Step>

  <Step title="Itera y Prueba">
    Haz preguntas de seguimiento o prueba diferentes formulaciones para ver como el bot maneja variaciones.
  </Step>
</Steps>

## Entender la Respuesta

Cada respuesta en el chat de pruebas incluye:

- **La respuesta**: Generada a partir del contenido de tu base de conocimiento
- **Fuentes citadas**: Que documentos o URLs uso el bot para formar su respuesta

<Tip>Si el bot no puede responder una pregunta, generalmente significa que la informacion relevante aun no esta en tu base de conocimiento. Intenta subir mas contenido o agregar la URL relevante.</Tip>

<Note>Para **workspaces de Discord**, la pagina de pruebas de recuperacion incluye un toggle de **Detector de Preguntas**. Cuando esta habilitado, simula la misma deteccion de preguntas que el bot usa en tus canales de Discord — para que puedas probar si el bot realmente responderia a un mensaje dado. Los workspaces de widget web responden a todas las preguntas, por lo que esta opcion no aplica.</Note>

## Sesiones de Chat

Tus conversaciones de prueba se guardan como **sesiones**. Puedes:

- Continuar una conversacion anterior
- Iniciar una nueva sesion para pruebas frescas
- Revisar sesiones pasadas para rastrear mejoras
