# Respuestas del bot

La pagina **Respuestas del bot** muestra cada respuesta que tu widget ha dado a los visitantes, junto con analiticas de rendimiento para entender como esta funcionando.

## Lista de respuestas

La vista principal muestra una lista cronologica de todas las respuestas del bot. Para cada respuesta puedes ver:

- **La pregunta**: lo que el visitante pregunto
- **La respuesta**: lo que el bot contesto
- **Timestamp**: cuando se envio la respuesta
- **Fuentes citadas**: de que conocimiento tiro el bot

## Resumen de analiticas

Arriba en la pagina, un **panel de estadisticas** te da un vistazo rapido:

| Metrica | Que muestra |
|---------|-------------|
| Respuestas totales | Cuantas respuestas ha dado el bot este mes |
| Tasa de respuesta | Con que frecuencia el bot responde correctamente |
| Tiempo medio de respuesta | Cuan rapido responde el bot |

<Tip>Si ves al bot dando respuestas incorrectas o incompletas en un tema concreto, anade mas contenido relevante a tu base de conocimiento y reconstruye.</Tip>
