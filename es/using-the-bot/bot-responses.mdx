# Respuestas del Bot

La pagina de **Respuestas del Bot** te muestra cada respuesta que tu bot ha dado en Discord, junto con analiticas de rendimiento para ayudarte a entender como se desempena.

## Lista de Respuestas

La vista principal muestra una lista cronologica de todas las respuestas del bot. Para cada respuesta, puedes ver:

- **La pregunta**: Lo que el usuario pregunto
- **La respuesta**: Lo que el bot respondio
- **El canal**: Donde sucedio la conversacion
- **Fecha y hora**: Cuando se envio la respuesta
- **Fuentes citadas**: De que conocimiento se baso el bot

## Resumen de Analiticas

En la parte superior de la pagina, un **panel de estadisticas** te da una vista rapida:

| Metrica | Que Muestra |
|---------|-------------|
| Total de Respuestas | Cuantas respuestas ha dado el bot este mes |
| Tasa de Respuesta | Con que frecuencia el bot responde preguntas exitosamente |
| Tiempo Promedio de Respuesta | Que tan rapido responde el bot |

<Tip>Si ves que el bot da respuestas incorrectas o incompletas sobre un tema especifico, agrega mas contenido relevante a tu base de conocimiento y reconstruye.</Tip>
