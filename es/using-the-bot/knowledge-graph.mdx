# Grafo de Conocimiento

El **Grafo de Conocimiento** es una visualizacion interactiva que muestra como se conecta el contenido de tu base de conocimiento. Mapea relaciones entre conceptos, temas y entidades encontrados en tus documentos.

## Que Muestra el Grafo

El grafo de conocimiento muestra:

- **Nodos**: Conceptos, temas o entidades individuales extraidos de tu contenido
- **Aristas**: Conexiones entre conceptos relacionados
- **Clusters**: Grupos de temas estrechamente relacionados que forman categorias naturales

## Como Usarlo

<Steps>
  <Step title="Abrir el Visor de Grafos">
    Abre la seccion **Grafo de Conocimiento** desde la barra lateral del dashboard.
  </Step>

  <Step title="Explorar Visualmente">
    El grafo carga con todos los conceptos de tu contenido mostrados como nodos conectados. Puedes:

    - **Desplazar**: Haz clic y arrastra para moverte por el grafo
    - **Zoom**: Usa la rueda del raton para acercar o alejar
    - **Clic en nodos**: Selecciona un nodo para ver sus detalles y conexiones
  </Step>

  <Step title="Buscar Temas">
    Usa la barra de busqueda para encontrar conceptos especificos. El grafo resaltara los nodos coincidentes y sus conexiones.
  </Step>

  <Step title="Usar la Leyenda">
    La leyenda muestra que significan los diferentes colores y tamanos de nodos. Los nodos mas grandes tipicamente representan conceptos mas conectados o centrales.
  </Step>
</Steps>

## Despues de Reconstruir

El grafo de conocimiento se actualiza automaticamente cuando reconstruyes tu base de conocimiento. Despues de agregar nuevo contenido y reconstruir, revisita el grafo para ver como la nueva informacion se conecta con tu conocimiento existente.
