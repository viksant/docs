# Guia de Configuracion en 5 Minutos

Esta es la forma mas rapida de pasar de cero a un chatbot de IA funcionando.

<Steps>
  <Step title="Crea Tu Cuenta" icon="user-plus">
    Ve a [bestchatbot.io](https://bestchatbot.io) y haz clic en **Comenzar**. Registrate con tu **cuenta de Google** o **email y contrasena**.
  </Step>

  <Step title="Crea un Workspace" icon="grid-2">
    Despues de iniciar sesion, crea un nuevo workspace. Un workspace contiene tu base de conocimiento, configuracion e integraciones.

    <Tip>Cada workspace esta vinculado a una plataforma — un servidor de Discord o un widget web. Crea workspaces separados si necesitas ambos.</Tip>
  </Step>

  <Step title="Elige Tu Plataforma" icon="window-maximize">
    Elige como quieres desplegar tu chatbot:

    - **Discord** — agrega un bot a tu servidor de Discord
    - **Web Widget** — integra un widget de chat en tu sitio web

    Para Discord, se te pedira iniciar sesion con tu cuenta de Discord para autorizar al bot en tu servidor. Para el web widget, obtendras un codigo para pegar en tu sitio.
  </Step>

  <Step title="Agrega Conocimiento" icon="book-open">
    Dale al bot algo de lo que aprender. Tienes tres opciones:

    - **Subir Documentos**: Arrastra y suelta PDFs, DOCX, TXT o archivos MD
    - **Agregar URLs**: Pega una URL de sitio web y deja que BestChatBot extraiga el contenido
    - **Que aprenda de Discord**: El bot captura automaticamente las respuestas valiosas de los moderadores que contienen informacion relevante para la base de conocimiento, con filtrado inteligente automatico

    <Note>Despues de agregar contenido, haz clic en **Reconstruir Base de Conocimiento** para que el bot procese tus datos.</Note>
  </Step>

  <Step title="Prueba y Lanza" icon="circle-check">
    Usa la pagina de **Pruebas de Recuperacion** en tu dashboard para hacer preguntas y verificar las respuestas del bot antes de lanzar.

    Cuando estes satisfecho, el bot ya esta activo. No se necesita ningun paso extra.
  </Step>
</Steps>
