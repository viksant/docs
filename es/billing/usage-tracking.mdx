# Uso del plan

BestChatBot rastrea tus **respuestas del widget mensuales** para que siempre sepas cuanto de tu plan has gastado. El uso se reinicia al principio de cada ciclo de facturacion.

## Ver tu uso

En el dashboard, encuentras la info de uso en varios sitios:

### Indicador de uso
Un indicador rapido en el sidebar o la barra superior muestra tu uso actual como porcentaje del limite de tu plan.

### Grafica de uso
La seccion **Billing** incluye una grafica del uso de respuestas en el tiempo, asi ves tendencias y prevees cuando te acercas al limite.

### Distribucion por workspace
Si tienes varios workspaces (varios widgets), puedes ver como se distribuye el uso entre ellos. Te ayuda a identificar que sitios son mas activos.

## Que cuenta como respuesta

Una **respuesta del bot** es cualquier respuesta que el bot genera y devuelve de verdad, tanto en tu widget en vivo **como** en la pagina Retrieval Testing. Una accion agentica ejecutada con exito tambien cuenta. Si el bot no entrega un resultado, no se te cobra.

| Accion | Cuenta como respuesta? |
|--------|------------------------|
| El widget responde a un mensaje del visitante | Si |
| Retrieval Testing produce una respuesta | Si |
| Una accion agentica se ejecuta con exito (ej: agenda una reunion) | Si |
| Una accion agentica solo se ofrece, el visitante no la ejecuta | No |
| Una accion agentica falla o no esta disponible | No |
| El bot no puede responder (no se genera respuesta) | No |
| Reconstruir la base de conocimiento | No |
| Subir documentos | No |

<Tip>Solo se te factura cuando el bot produce un resultado real. Ofrecer una accion, fallar o no encontrar respuesta es gratis.</Tip>

## Acercandote al limite

Cuando te acercas al limite mensual:

- El indicador de uso cambia de color para avisarte
- Puedes actualizar tu plan en cualquier momento para tener mas respuestas

<Warning>Cuando alcanzas el limite mensual, el widget deja de responder a visitantes hasta el siguiente ciclo de facturacion o hasta que actualices el plan.</Warning>
