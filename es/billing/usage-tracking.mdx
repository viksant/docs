# Seguimiento de Uso

BestChatBot rastrea tus **respuestas mensuales del bot** para que siempre sepas cuanto de tu plan has usado. El uso se reinicia al comienzo de cada ciclo de facturacion.

## Ver Tu Uso

En el dashboard, encontraras informacion de uso en varios lugares:

### Indicador de Uso
Un indicador rapido en la barra lateral o barra superior muestra tu uso actual como porcentaje del limite de tu plan.

### Grafico de Uso
La seccion de **Facturacion** incluye un grafico mostrando tu uso de respuestas a lo largo del tiempo, para que puedas ver tendencias y predecir cuando podrias acercarte a tu limite.

### Distribucion por Workspace
Si tienes multiples workspaces, puedes ver como se distribuye el uso entre ellos. Esto te ayuda a identificar que comunidades son mas activas.

## Que Cuenta Como Respuesta

Cada vez que el bot envia una respuesta — ya sea en Discord o a traves del widget web — cuenta como **una respuesta del bot**. Lo siguiente **no** cuenta:

| Accion | Cuenta Como Respuesta? |
|--------|------------------------|
| El bot responde una pregunta en Discord | Si |
| El bot responde a traves del widget web | Si |
| Pruebas en la pagina de Pruebas de Recuperacion | No |
| El bot omite un mensaje (sin respuesta relevante) | No |
| Reconstruir la base de conocimiento | No |
| Subir documentos | No |

<Tip>Usa la pagina de **Pruebas de Recuperacion** para probar todo lo que quieras. No afecta tu conteo de respuestas.</Tip>

## Acercandote a Tu Limite

Cuando estes cerca de tu limite mensual:

- El indicador de uso cambia de color para advertirte
- Puedes mejorar tu plan en cualquier momento para obtener mas respuestas

<Warning>Una vez que alcances tu limite mensual, el bot dejara de responder en Discord hasta el siguiente ciclo de facturacion o hasta que mejores tu plan.</Warning>
