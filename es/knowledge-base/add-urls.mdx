# Agregar URLs

La pestana **Enlaces** en el Gestor de Documentos te permite agregar contenido web a tu base de conocimiento. En vez de copiar y pegar de sitios web, BestChatBot extrae el contenido por ti.

## Metodos de Extraccion

BestChatBot ofrece tres formas de agregar contenido web:

<CardGroup cols={3}>
  <Card title="URL Directa" icon="link">
    Pega la URL de una sola pagina. El bot extrae solo esa pagina.
  </Card>
  <Card title="Sitemap" icon="sitemap">
    Proporciona una URL de sitemap y BestChatBot descubre todas las paginas automaticamente.
  </Card>
  <Card title="Rastreo" icon="spider">
    Ingresa una URL inicial y BestChatBot rastrea el sitio siguiendo enlaces para descubrir paginas.
  </Card>
</CardGroup>

## Como Agregar URLs

<Steps>
  <Step title="Abrir el Gestor de Documentos">
    Ve al **Gestor de Documentos** desde la barra lateral del dashboard y cambia a la pestana **Enlaces**.
  </Step>

  <Step title="Elige Tu Metodo">
    Selecciona si quieres agregar una **URL Directa**, **Sitemap** o **Rastreo**.
  </Step>

  <Step title="Ingresa la URL">
    Pega la URL en el campo de entrada. Por ejemplo:

    - **Directa:** `https://tusitio.com/faq`
    - **Sitemap:** `https://tusitio.com/sitemap.xml`
    - **Rastreo:** `https://tusitio.com/docs`
  </Step>

  <Step title="Configurar Filtros de URL (Opcional)">
    Al usar **Rastreo** o **Sitemap**, puedes configurar filtros de patron de URL para incluir o excluir paginas especificas. Esto te permite enfocar el extractor en el contenido que importa.
  </Step>

  <Step title="Iniciar Extraccion">
    Haz clic en el boton para comenzar la extraccion. Veras el progreso a medida que las paginas se descubren y procesan.

    <Note>El tiempo de extraccion depende del numero de paginas. Una sola pagina toma segundos; un rastreo completo puede tomar varios minutos.</Note>
  </Step>

  <Step title="Reconstruir Base de Conocimiento">
    Despues de que la extraccion termine, recuerda **Reconstruir la Base de Conocimiento** para que el bot pueda usar el nuevo contenido.

    <Warning>Los cambios en tus URLs (nuevas extracciones o eliminaciones) **no se aplican** hasta que reconstruyas. El bot continua usando la version anterior de la base de conocimiento hasta entonces.</Warning>
  </Step>
</Steps>

## Limites de Paginas Extraidas

Cada plan incluye un numero determinado de paginas extraidas:

| Plan | Paginas Extraidas |
|------|-------------------|
| Free | 5 |
| Starter | 30 |
| Pro | 75 |
| Business | 150 |

<Tip>Usa **URL Directa** para tus paginas mas importantes primero. Reserva el rastreo para cuando necesites cobertura completa.</Tip>

## Gestionar Contenido Extraido

Las paginas extraidas aparecen junto con los documentos subidos en tu base de conocimiento. Puedes:

- Ver la URL y fecha de extraccion
- Eliminar paginas extraidas individuales
- Re-extraer una URL para obtener contenido actualizado
