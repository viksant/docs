# Reconstruir base de conocimiento

Tras anadir o quitar contenido — documentos o URLs — necesitas **reconstruir** la base de conocimiento. Esto procesa tu contenido y lo deja disponible para que el bot lo use al responder.

## Cuando reconstruir

Deberias reconstruir tu base de conocimiento cuando:

- Subes nuevos documentos
- Scrapeas nuevas URLs
- Borras contenido existente

<Warning>El contenido nuevo **no** esta disponible para el bot hasta que reconstruyes. Si subes un documento y no reconstruyes, el bot no sabra que existe.</Warning>

## Como reconstruir

<Steps>
  <Step title="Abre el panel de Base de conocimiento">
    En el sidebar del dashboard, busca la seccion **Base de conocimiento** o el boton de reconstruir en el Document Manager.
  </Step>

  <Step title="Pulsa Reconstruir">
    Pulsa el boton **Reconstruir base de conocimiento** para iniciar el proceso.
  </Step>

  <Step title="Espera a que termine">
    Veras un indicador de progreso con el estado de la reconstruccion. El tiempo depende del volumen y densidad de tu contenido — bases pequenas terminan rapido, bases grandes con muchos documentos y URLs tardan mas.
  </Step>

  <Step title="Verifica el estado">
    Cuando termine, el estado se actualiza para mostrar que la reconstruccion fue exitosa. El bot ya esta usando tu ultimo contenido.
  </Step>
</Steps>

## Que pasa durante una reconstruccion

Cuando reconstruyes, BestChatBot reemplaza la base de conocimiento entera con una version fresca construida desde tus fuentes actuales:

1. **Limpia** la base de conocimiento existente
2. **Descarta** las fuentes marcadas como eliminadas
3. **Trae** contenido para fuentes pendientes (p. ej., URLs nuevas sin scrapear)
4. **Reprocesa** todas las fuentes activas desde cero
5. **Activa** el nuevo conocimiento para que el bot lo use

<Warning>El widget **no respondera** a preguntas mientras la reconstruccion esta en curso, para evitar respuestas incorrectas o incompletas.</Warning>

<Tip>Puedes seguir usando el dashboard mientras la reconstruccion esta en curso. Solo afecta temporalmente a la capacidad del bot de responder.</Tip>

## Limites diarios de reconstruccion

Cada plan incluye un numero limitado de reconstrucciones por dia:

| Plan | Reconstrucciones diarias |
|------|--------------------------|
| Free | 1 |
| Starter | 1 |
| Pro | 2 |
| Business | 3 |

<Note>Al alcanzar tu limite diario, esperas al dia siguiente o actualizas tu plan para mas reconstrucciones.</Note>

## Buenas practicas

| Practica | Por que |
|----------|---------|
| Reconstruye tras subidas en lote | Mas eficiente que reconstruir tras cada archivo |
| Recuerda que el widget se pausa durante reconstrucciones | No responde hasta que termina |
| Verifica el estado antes de probar | Asegurate de que termino bien |
