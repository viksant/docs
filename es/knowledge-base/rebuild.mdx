# Reconstruir Base de Conocimiento

Despues de agregar o eliminar contenido (documentos, URLs o entradas Q&A) necesitas **reconstruir** la base de conocimiento. Esto procesa tu contenido y lo hace disponible para que el bot lo use al responder preguntas.

## Cuando Reconstruir

Deberias reconstruir tu base de conocimiento cuando:

- Subes nuevos documentos
- Extraes nuevas URLs
- Eliminas contenido existente
- Quieres incorporar entradas Q&A recientes de Discord

<Warning>El nuevo contenido **no** esta disponible para el bot hasta que reconstruyas. Si subes un documento y no reconstruyes, el bot no sabra de su existencia.</Warning>

## Como Reconstruir

<Steps>
  <Step title="Abrir el Panel de Base de Conocimiento">
    En la barra lateral del dashboard, busca la seccion **Base de Conocimiento** o el boton de reconstruir en el Gestor de Documentos.
  </Step>

  <Step title="Hacer Clic en Reconstruir">
    Haz clic en el boton **Reconstruir Base de Conocimiento** para iniciar el proceso.
  </Step>

  <Step title="Esperar a que Termine">
    Veras un indicador de progreso mostrando el estado de la reconstruccion. El tiempo depende de la cantidad y densidad de tu contenido — bases de conocimiento mas pequenas terminan rapido, mientras que las mas grandes con muchos documentos y URLs tardan mas.
  </Step>

  <Step title="Verificar el Estado">
    Una vez completa, el estado se actualizara para mostrar que la reconstruccion fue exitosa. El bot ahora usa tu contenido mas reciente.
  </Step>
</Steps>

## Que Sucede Durante una Reconstruccion

Cuando reconstruyes, BestChatBot reemplaza toda la base de conocimiento con una version nueva construida a partir de tus fuentes actuales:

1. **Limpia** la base de conocimiento existente completamente
2. **Descarta** las fuentes marcadas como eliminadas
3. **Obtiene** el contenido de fuentes pendientes (ej: URLs nuevas que aun no se han extraido)
4. **Re-procesa** todas las fuentes activas desde cero para construir la nueva base de conocimiento
5. **Activa** el nuevo conocimiento para que el bot lo use

<Warning>El bot **no respondera** preguntas mientras una reconstruccion este en progreso, para evitar dar respuestas incorrectas o incompletas.</Warning>

<Tip>Puedes seguir usando el dashboard mientras una reconstruccion esta en progreso. La reconstruccion solo afecta la capacidad del bot de responder preguntas temporalmente.</Tip>

## Limites de Rebuilds Diarios

Cada plan incluye un numero limitado de reconstrucciones por dia:

| Plan | Rebuilds Diarios |
|------|------------------|
| Free | 1 |
| Starter | 3 |
| Pro | 10 |
| Business | 20 |

<Note>Una vez que alcances tu limite diario de rebuilds, tendras que esperar hasta el dia siguiente o mejorar tu plan para obtener mas reconstrucciones.</Note>

## Mejores Practicas de Reconstruccion

| Practica | Por Que |
|----------|---------|
| Reconstruir despues de subidas masivas | Mas eficiente que reconstruir despues de cada archivo |
| El bot se pausa durante los rebuilds | No respondera preguntas hasta que termine |
| Verificar el estado antes de probar | Asegurate de que la reconstruccion termino exitosamente |
| Reconstruir semanalmente para aprendizaje Q&A | Incorporar las respuestas mas recientes de moderadores |
