# Sistema de Aprendizaje Q&A

Una de las funciones mas poderosas de BestChatBot es su capacidad de **aprender de conversaciones reales** en tu servidor de Discord. Cuando los moderadores responden preguntas, el bot recuerda esas respuestas para el futuro.

## Como Funciona

<Steps>
  <Step title="Un Usuario Hace una Pregunta">
    Alguien en tu comunidad hace una pregunta en un canal donde el bot esta activo.
  </Step>

  <Step title="Un Moderador Responde">
    Un moderador o administrador del servidor proporciona una respuesta util a la pregunta.
  </Step>

  <Step title="BestChatBot Evalua el Intercambio">
    El bot aplica filtrado inteligente para determinar si la respuesta del moderador aporta informacion valiosa y relevante para la base de conocimiento. Solo las respuestas que contribuyen conocimiento nuevo y factual se capturan como **entradas Q&A**. Las respuestas casuales, mensajes fuera de tema e informacion redundante se filtran automaticamente.
  </Step>

  <Step title="Preguntas Futuras Obtienen Mejores Respuestas">
    Cuando surjan preguntas similares en el futuro, el bot puede usar estas respuestas reales de moderadores para dar respuestas mas precisas y especificas de tu comunidad.
  </Step>
</Steps>

## Ver Entradas Q&A

Puedes ver todos los pares Q&A capturados en el **Gestor de Documentos**:

1. Abre el **Gestor de Documentos** desde la barra lateral
2. Busca las entradas marcadas como fuentes **Q&A**
3. Cada entrada muestra la pregunta original y la respuesta del moderador

<Frame>
  <img src="/images/qa-screen-front-end.png" alt="Pestana de Aprendizaje Automatico mostrando entradas Q&A capturadas" />
</Frame>

Haz clic en cualquier entrada Q&A para ver la pregunta completa y la respuesta del moderador:

<Frame>
  <img src="/images/qa-screen-detailed-front-end.png" alt="Modal de Contenido Q&A mostrando la pregunta y respuesta del moderador" />

<Note>Las entradas de Q&A se incluyen en la base de conocimiento como documentos subidos y paginas extraidas. Despues de un [rebuild](/es/knowledge-base/rebuild), el bot puede usarlas para responder preguntas.</Note>

<Warning>El Sistema de Aprendizaje Q&A es una funcion **exclusiva de Discord**. No esta disponible para workspaces de widget web.</Warning>

## Consejos Para Mejor Aprendizaje Q&A

- **Fomenta respuestas detalladas de moderadores**: Cuanto mas completa sea la respuesta, mejor aprende el bot
- **Manten las respuestas en tema**: Respuestas fuera de tema pueden confundir al bot
- **Reconstruye periodicamente**: Reconstruye la base de conocimiento para incorporar las entradas Q&A recientes
