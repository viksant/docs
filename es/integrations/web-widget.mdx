# Web Widget

<Note>El web widget esta **proximamente**. Esta pagina se actualizara cuando se lance.</Note>

Estamos construyendo un widget de chat que puedes integrar directamente en tu sitio web. La misma IA, la misma base de conocimiento, nueva superficie.

## Que Esperar

El web widget permitira a los visitantes de tu sitio web hacer preguntas y obtener respuestas instantaneas de la misma base de conocimiento que usa tu bot de Discord. Una base de conocimiento, multiples canales.

## Funciones Planeadas

- **Etiqueta script plug-and-play** para cualquier sitio web
- **Misma base de conocimiento** que tu bot de Discord
- **Apariencia personalizable** para coincidir con tu marca
- **Sin configuracion extra** si ya tienes una base de conocimiento

## Mantente Actualizado

Anunciaremos el lanzamiento del web widget a traves de nuestra comunidad de Discord y actualizaciones por email. Si estas en un plan de pago, tendras acceso anticipado.
