# Stripe

**Categoria: Pagos.** Conecta Stripe y tu widget podra gestionar facturacion y suscripciones por tus visitantes, dentro del propio chat.

<Note>Las integraciones estan disponibles en los planes **Pro** y **Business**.</Note>

## Que puede hacer tu bot

| Accion | Que ocurre |
|--------|------------|
| **Ver una suscripcion** | Muestra al visitante su plan actual. |
| **Ver facturas y metodos de pago** | Permite al visitante ver facturas y metodos de pago guardados. |
| **Gestionar suscripcion** | Abre el portal de facturacion para que el visitante actualice su plan. |
| **Iniciar una compra** | Genera un enlace de checkout para el visitante. |
| **Explorar productos y precios** | Lista lo que esta disponible para comprar. |

## Como conectar

<Steps>
  <Step title="Abre Integraciones" icon="plug">
    En el dashboard de tu workspace, abre la pestana **Integraciones** y busca **Stripe**.
  </Step>
  <Step title="Conecta" icon="link">
    Haz clic en **Conectar**. Se abre un popup seguro. Introduce tu API key de Stripe. Tus credenciales van al formulario seguro, nunca al chat.
  </Step>
  <Step title="Listo" icon="circle-check">
    Una vez conectada, las acciones de Stripe quedan disponibles en tu widget de inmediato.
  </Step>
</Steps>

<Note>Necesitas un rol adecuado para conectar: conectar integraciones requiere rol **Editor**, **Admin** u **Owner**. Consulta [Miembros y roles](/es/workspace/members-roles).</Note>

## Una por categoria

Stripe es la unica opcion en la categoria **Pagos**, asi que nunca entra en conflicto con otra integracion.
