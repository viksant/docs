# Invite the Bot to Your Server

Once you've created your account, the next step is to add BestChatBot to your Discord server.

## How to Invite

<Steps>
  <Step title="Open the Dashboard">
    Log in to [bestchatbot.io](https://bestchatbot.io) and navigate to your dashboard.
  </Step>

  <Step title="Click Add Bot to Server">
    You'll see an option to **Add Bot to Server**. Click it to start the invitation process.
  </Step>

  <Step title="Choose Your Server">
    A Discord popup will appear showing the servers where you have admin permissions. Select the server you want to add BestChatBot to.
  </Step>

  <Step title="Authorize Permissions">
    Review the permissions BestChatBot needs and click **Authorize**. The bot requests only what's necessary to function:

    - **Read Messages**: Sees questions from your community
    - **Send Messages**: Replies with answers
    - **Read Message History**: Understands conversation context
    - **Embed Links**: Formats responses with rich content

    <Warning>Do not remove the bot's permissions after inviting it. The bot needs all listed permissions to function properly.</Warning>
  </Step>

  <Step title="Confirm in Dashboard">
    After authorization, you'll be redirected back to the dashboard. Your server will now appear as a connected workspace.
  </Step>
</Steps>

## Multiple Servers

You can add BestChatBot to multiple Discord servers. Each server becomes a separate **workspace** with its own:

- Knowledge base
- Channel configuration
- Response preferences
- Usage tracking

<Tip>Switch between workspaces using the workspace selector at the top of the dashboard sidebar.</Tip>
